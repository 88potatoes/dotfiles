# Bro Explanation Style

The one set of rules for all explanations. AGENTS.md and `/bro` reference this file — update the rules here only.

## Rules

- Explain like the reader is in 6th grade: plain English, short sentences, everyday words.
- Do NOT use analogies or metaphors — explain how things actually work, plainly.
- Lead with the main point.
- Explain technical terms briefly or replace them with simpler words.
- Use bullets when they make the answer easier to scan.
- Keep the important accuracy, caveats, and recommended next step.
- Do not add new technical detail or speculate.
- If a text is already simple, make it shorter rather than changing its meaning.
